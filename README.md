# 🍽 Recipe Bot — семейная книга рецептов в Telegram

Закрытый Telegram-бот, где вы, семья и друзья ведёте одну общую книгу рецептов.

## Что умеет

- **🍲 Свои блюда** — название, фото (сколько угодно), ингредиенты, приготовление, время готовки,
  число порций, теги.
- **📚 Найденные рецепты** — отдельный раздел для рецептов из интернета: просто пришлите фото или
  скриншот, бот предложит его сохранить. Подпись к фото попадает в заметки.
- **🔍 Поиск** — напишите боту любое слово: ищет по названию, ингредиентам, шагам, заметкам и тегам
  (без учёта регистра, «е» = «ё»). Несколько слов — рецепты, где есть все слова.
- **🏷 Теги** — список тегов со счётчиками, по нажатию — рецепты с тегом.
- **✏️ Правка** — любое поле, добавить или заменить фото, перенести рецепт между разделами.
- **🗑 Удаление** — может автор рецепта или администратор.
- **Доступ по приглашениям** — посторонние ничего не видят. Вы — администратор, другим даёте одноразовый код.
- **/backup** — бот присылает файл базы данных.

## Запуск на своём компьютере

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/); в Windows при установке
отметьте **Add Python to PATH**).

1. **Создайте бота.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите токен.
2. **Узнайте свой Telegram ID** у [@userinfobot](https://t.me/userinfobot).
3. **Скачайте проект** (`git clone` или кнопка *Code → Download ZIP*).
4. **Запустите:**
   - Windows: двойной клик по `run.bat`. В первый раз он установит зависимости и откроет `.env`
     в Блокноте — впишите `BOT_TOKEN` и `ADMIN_IDS`, сохраните и запустите `run.bat` снова.
   - macOS / Linux: `./run.sh` (так же создаст `.env`, заполните его и запустите ещё раз).
5. Откройте своего бота в Telegram и нажмите **Start**.

Бот работает, пока открыто окно с ним. Компьютер выключен — бот не отвечает, но ничего не теряется:
сообщения, присланные в это время, он обработает при следующем запуске (Telegram хранит их до суток).

Если Telegram у вас открывается только через VPN/прокси, укажите `TELEGRAM_PROXY` в `.env`
(например `socks5://127.0.0.1:1080`).

## Как пригласить семью и друзей

- `/invite` — бот выдаст одноразовую ссылку. Перешлите её человеку: он откроет её, нажмёт Start и сразу попадёт в книгу.
  Вместо ссылки можно продиктовать 8-значный код — его нужно просто отправить боту.
- `/adduser 123456789 Мама` — добавить по Telegram ID (человек увидит свой ID, если напишет боту).
- `/users` — кто есть в книге, `/remove ID` — убрать доступ (его рецепты останутся).

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Главное меню |
| `/add` | Добавить своё блюдо |
| `/found` | Сохранить найденный рецепт |
| `/search слово` | Поиск |
| `/cancel` | Отменить текущее действие |
| `/invite`, `/users`, `/adduser`, `/remove`, `/backup` | Только для администратора |

## Где хранятся данные

Всё лежит в одном файле `data/recipes.db` (SQLite). Сами фото хранятся на серверах Telegram, в базе — их
идентификаторы, поэтому:

- для резервной копии достаточно этого файла (или команды `/backup`);
- **не меняйте токен бота и не создавайте нового бота** для той же базы — фото привязаны к боту
  и с другим ботом не откроются.

## Для разработки

```sh
python -m venv venv
venv/bin/pip install -r requirements-dev.txt   # Windows: venv\Scripts\pip ...
venv/bin/python -m pytest
```

Структура:

```
bot/
  __main__.py      запуск и регистрация обработчиков
  config.py        настройки из .env
  db.py            SQLite: пользователи, приглашения, рецепты, фото, теги, поиск
  ui.py            тексты, клавиатуры, карточка рецепта
  handlers/
    common.py      проверка доступа, /start, /help
    flows.py       пошаговое добавление и правка
    browse.py      просмотр, списки, теги, поиск, удаление
    menu.py        кнопки главного меню
    admin.py       приглашения, участники, бэкап
tests/             тесты базы и сквозные сценарии бота с поддельным Telegram API
```
